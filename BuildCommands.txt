JobTracker build command entry point

The maintained command catalog is For-Agent/Docs/build.md.
Start with docs/BUILDING.md for Qt 6.10.3, toolchain and preset setup.

Catalog sections:
- Windows Build: Debug configure/build and explicit development runtime.
- Windows Build With Tests: isolated test-enabled build and CTest.
- Windows Release Build And Tests: production Release and separate tests.
- Windows Release Staging / Offline Installer: direct staging, local runtime,
  one native x64 Setup EXE and separate deployment verification.
- Linux Build: Ninja Debug/Release production/test commands; NOT RUN on Windows.

Run commands one at a time from the repository root in PowerShell. Codex must
use elevated tool access for each CMake build from the first attempt and wait
for its final exit code. Do not delete build trees or evidence without approval.
Normal builds do not install, package or publish. Git writes remain restricted.

This compatibility pointer intentionally contains no duplicate executable
commands. Entry point: Tasks/Offline-Installer/00_RUN_NEXT.md.
Current status: Tasks/Offline-Installer/STATUS.md.
