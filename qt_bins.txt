JobTracker Qt runtime entry point

Exactly Qt 6.10.3 is required on Windows and Linux.
Use For-Agent/Docs/build.md as the canonical command catalog:
- Local Development Runtime And Startup: explicit JobTrackerApp_dev_runtime.
- Windows Release Staging: install-time Qt/QML/platform/SQLite deployment.
- Isolated Staging Smoke Check: separate test probe and retained private copy.

Do not use ad-hoc windeployqt output or a Debug/test tree as a release payload.
Normal builds only compile/link. Release staging uses a fresh absolute prefix
and relative qt.conf, excludes the MSVC CRT, and is checked against
packaging/windows/payload-files.txt. Setup supplies the hybrid CRT policy.

See For-Agent/Docs/windows-release.md and docs/WINDOWS-INSTALLER.md.
