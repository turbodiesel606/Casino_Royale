# JobTracker Offline Installer

This directory contains the native x64 Inno Setup project, its build/validation
scripts, identity templates, runtime lock, payload inventory, icon, and notice.
Generated customer output is confined to `output/`.

See the [installer reference](../For-Agent/Docs/installer.md) for file
responsibilities, prerequisites, build commands, and maintenance behavior, and
[installer testing](../For-Agent/Docs/installer-testing.md) for verification.
