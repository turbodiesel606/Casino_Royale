This is a future sequence after blockers are addressed, not authorization to
publish. The updated [developer handoff](../../../docs/WINDOWS-RELEASE.md#manual-publication-after-clearance)

   affected tests and a new exact-payload audit. Preserve current evidence.

   [stage](../../Docs/build.md#windows-release-staging), then

   the [matching version-specific Online Setup](../../Docs/build.md#windows-version-locked-online-installer)
