## Goal and actual outcome

Completed stage 07 only. Added and compiled the local-payload Inno Setup
foundation using installed Inno Setup 6.7.1 and the verified stage-06 archive.
The installer embeds the 148 verified extracted files. It is a local fixture,
not an Online Installer, and does not download or launch JobTracker.

The script uses the stage-05 generated identity for product/version, setup icon,
shortcut icons and uninstall icon. A separate wrapper verifies the archive via
the existing stage-06 verifier, checks its executable against the chosen Release
build, invokes Inno, and saves compiler output and hashes. Normal CMake paths
are unchanged. The verifier gained an optional structured `-PassThru` result
for this packaging consumer; its existing console interface remains unchanged.

Two version-independent identities are represented in the compiled script:

| Mode | AppId | Uninstall scope | Default destination | Shortcut scope |
|---|---|---|---|---|
| Current user | `JobTracker.CurrentUser` | HKCU, `JobTracker.CurrentUser_is1` | `%LocalAppData%\Programs\JobTracker` | Current-user Start Menu/desktop |
| All users | `JobTracker.AllUsers` | HKLM, `JobTracker.AllUsers_is1` | `%ProgramFiles%\JobTracker` | Common Start Menu/desktop |

Current-user is the non-elevating default; Inno's explicit mode dialog can select
all-users and request elevation. `UsePreviousPrivileges=no` preserves the dialog
with the dynamic AppId; native previous-directory lookup uses the selected
identity. The destination remains editable. Separate IDs, registration roots
and localized shortcut leaf names support independent representation of the
two modes, rather than relying on a shared ID alone.

The decisions were checked against primary Inno documentation for
[privilege overrides](https://jrsoftware.org/ishelp/topic_setup_privilegesrequiredoverridesallowed.htm),
[AppId](https://jrsoftware.org/ishelp/topic_setup_appid.htm),
[previous privileges](https://jrsoftware.org/ishelp/topic_setup_usepreviousprivileges.htm),
[install modes](https://jrsoftware.org/ishelp/topic_admininstallmode.htm) and
[previous paths](https://jrsoftware.org/ishelp/topic_setup_usepreviousappdir.htm).

English and Russian are included. English is first for unsupported UI languages;
system UI-language detection and an always-available language dialog are enabled,
following Inno's [language selection rules](https://jrsoftware.org/ishelp/topic_languagessection.htm).
The Start Menu shortcut is unconditional; the desktop task is unchecked by
default. Custom scope labels, desktop text and conflict messages are localized.

An installer-owned `JobTracker.install.ini` marker rejects an existing marker
for another scope at the same destination. Standard uninstall removes its
registered payload/shortcuts and that one marker, without recursive deletion
of the install folder or access to application data. Full path-alias/nesting,
upgrade and downgrade safety belongs to stage 10. Automatic application closure
and relaunch are disabled; the explicit manual-close workflow remains stage 11.
