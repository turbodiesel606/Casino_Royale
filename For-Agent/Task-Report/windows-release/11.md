### Detection and cancellation policy

- `ManualClose.iss` probes the exact `{app}\bin\JobTrackerApp.exe` using
  `CreateFileW`, write access, all sharing modes and `OPEN_EXISTING`. This opens
  without writing/truncating. A mapped executable produces a sharing failure
  (actual fixture result: Windows error 32). An independent same-name executable
  elsewhere is unaffected. No process-name enumeration or PID/user guessing occurs.
- Existing path/reparse checks remain in use. Missing files are accepted;
  inaccessible/read-only/otherwise unverifiable files fail closed. The message
  distinguishes a file in use from an unknown access failure and includes its path.
  File use can be caused by another process; the policy does not claim to identify
  a specific PID or Windows user.
- English/Russian messages request manual closure and offer Retry/Cancel. Retry
  repeats the probe. Another session using this exact executable must close it
  manually too; no impersonation, signaling or termination is attempted.
- Setup checks before download/prerequisites, after them, at `ssInstall`, and
  before every generated payload/CRT/notice copy. The per-file check additionally
  probes its destination. Uninstall checks at initialization, `usAppMutexCheck`
  and `usUninstall` immediately before native deletion begins.
- Automatic Restart Manager close/restart stays disabled. Setup rejects
  `/CLOSEAPPLICATIONS`, `/FORCECLOSEAPPLICATIONS`, `/RESTARTAPPLICATIONS`,
  `/NOCANCEL` and `/LOADINF`, which could override close/cancel policy. Rejecting
  INF replay avoids relying on a second read of mutable input; `/SAVEINF` remains.
- Inno swallows exceptions from `BeforeInstall` and `Check`. The final per-file
  implementation returns False, latches later guarded copies off, and requests
  acknowledged native cancellation. It temporarily satisfies the native
  progress-form/button visibility/enabled requirements, suppresses the redundant
  cancel confirmation, then restores UI state. This can briefly show progress
  even for `/VERYSILENT`. The verified native path exits 5 and enters rollback
  before shortcut/INI/registry commit. It never closes the application.
- Silent calls skip the custom Retry/Cancel dialog. **Unattended Setup requires
  both `/VERYSILENT` and `/SUPPRESSMSGBOXES`**: Inno otherwise shows its own
  preparation-error summary. The early silent uninstall gate and the tested
  late-copy cancellation need no such summary. This distinction was found in
  retained logs and corrected before final acceptance.

These checks are not a transaction-wide launch lock. Windows sharing remains
the final protection for loaded binaries between a probe and a file operation.
Do not reopen the affected copy until maintenance finishes. A failure after
earlier upgrade files were copied can require repair with the same/newer
installer; a generic rollback log is not proof that the old binary set was
restored. No personal data is opened or deleted by this work.
