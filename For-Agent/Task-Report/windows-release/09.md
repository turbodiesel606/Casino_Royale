### Failure, cancellation and restart behavior

All-users detection checks the x64 registration in both registry views,
`Installed=1`, major 14, numeric minimum version and the system CRT files.
Existing App-Local MSVC/UCRT DLLs in that destination block installation rather
than silently shadowing the system runtime or being deleted.

The native prerequisite download verifies the compiled SHA-256, exact size and
package version before execution. The installer runs `/install /passive
/norestart`, or `/quiet` for silent Setup, and waits. Exit 0 and 1638 succeed
only if the runtime is compatible afterward. Cancellation 1602, its Burn HRESULT,
and the newer-version HRESULT are handled explicitly. Other errors stop before
JobTracker file/registration changes. Results 3010/1641 require a restart and
rerun; retry in the same Setup process cannot bypass that requirement.
This uses Inno's documented
[PrepareToInstall restart contract](https://jrsoftware.org/ishelp/topic_scriptevents.htm)
and Microsoft's [installer result definitions](https://learn.microsoft.com/en-us/windows/win32/msi/error-codes).

Messages and ready-page runtime explanations have English/Russian forms.
Cleanup is restricted to the downloaded executable in Setup's private temporary
directory. A successfully installed machine prerequisite is not rolled back if
JobTracker installation later fails, and JobTracker uninstall never removes it.
Actual elevated prerequisite installation and reboot behavior were **NOT_RUN**.
