- **E006, sandbox environment:** the first full Debug CTest executed 20 suites but failed 10 at test-profile setup (225 Qt PASS, 26 FAIL). The existing `LogCapture` needs its own UUID directory under `~/.qttest/state`; sandbox access and an initial ptrace attempt were blocked. An unchanged access-enabled LogWriter case and then the entire full Debug suite passed. The trace shows only fixture-owned UUID creation/use/cleanup. No source or system configuration workaround was made.
- **Release production interruption:** one command received SIGTERM/143 without compiler-error output. Exact cause is unknown. A read-only host process check found no remaining project build process; the identical incremental retry passed. This is not counted as a compiler regression.
- **Native Release geometry, origin not fully established:** the default combined native invocation passed three bootstrap rows but held the shell at 1854x1011 instead of requested 1180x720, failing `ShellBaseline.cpp:272` before interaction/capture. `qml/Main.qml`, `App.cpp` and `AppBootstrap.cpp` remain byte-identical to R0, with no explicit maximization setting. The unchanged minimum-shell case passed under Qt's supported `-qwindowgeometry 1180x720` launch option. Selection and initial geometry differ from the failed invocation, so this does not establish a single-factor cause or turn the original run into success. Preserve the failed log and recheck default native sizing on a controlled desktop.
